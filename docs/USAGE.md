## 安装与配置

### 环境要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| ComfyUI | 0.42.x | 实测 0.42.1；更老版本可能缺 `widget.inputEl` |
| Python | ≥ 3.10 | 用了 `X \| None` 注解；实测 3.13.12 |
| 第三方包 | 无 | 只用标准库 + ComfyUI 自带 `folder_paths` |
| 磁盘 | 约 45 MB | 立绘 22 MB + 母题预览 14 MB + 数据与代码 8 MB |
| 网络 | 不需要 | 运行时零联网 |

### 两种安装方式

**git clone**（可 `git pull` 升级）

```bash
cd <ComfyUI>/custom_nodes
git clone https://github.com/lingdongbudong/Comfyui-K2-Editorial.git
```

**ZIP 手动**（干净但升级要重下）

下载 `Code → Download ZIP` → 解压到 `<ComfyUI>/custom_nodes/`，确认最终路径是
`custom_nodes/Comfyui-K2-Editorial/__init__.py`（**不要套一层同名目录**）。

### 三步验证安装

```bash
# ① 启动日志：重启 ComfyUI 后找这行
#    [K2-Editorial] v1.13.0 已加载：['K2EditorialBuilder']

# ② 节点已注册
curl -s --noproxy '*' http://127.0.0.1:8188/object_info/K2EditorialBuilder | head -c 120

# ③ 数据与装配链路都通（17 项，含 HTTP 冒烟）
python tests/run_all.py --http
```

第 ③ 步全绿说明：数据文件完整、553 条母题装配无告警、缓存与原子写正常、端点可访问。

### 数据源配置

角色 / 服装数据有两个来源，用环境变量选：

| `K2ED_ANIMA_SOURCE` | 行为 |
| --- | --- |
| `auto`（默认） | 装了 Comfyui-Anima-Wardrobe-V6 就用它的实时数据，否则回落内置副本 |
| `live` | 只用 Anima 实时数据（没装则角色页空白） |
| `bundle` | 只用内置副本（`presets/anima/` + `thumbs/anima/`） |

Windows 设置示例（启动前）：

```bat
set K2ED_ANIMA_SOURCE=bundle
```

内置副本是**打包时快照**（2026-11-12：2432 角色 / 2432 张图 / 98 套服装），
不跟 Anima 自动同步。要更新快照，从 Anima 的 `presets/` 重新拷一份过来。

### 数据文件：哪些随仓库、哪些本机生成

| 文件 | 来源 | 能否改 |
| --- | --- | --- |
| `presets/seeds_motifs.json` | 仓库（原始 32 条母题） | 改完**要重启** |
| `presets/seeds_extra.json` | 仓库（手工新增母题，不被覆盖） | 改完**要重启** |
| `presets/manifest.json` | 仓库（面板数据层：中文名 / 缩略图 / 标签） | 改完刷新面板即可 |
| `presets/characters.json` | 仓库（2 位手写角色，质量高于自动生成） | 可改 |
| `presets/costumes.json` | 仓库（8 套通用版型 + 推荐顺序） | 可改 |
| `presets/motif_names_zh.json` 等 5 份 | 仓库（**构建输入**，运行时不读） | 别删，构建脚本要用 |
| `presets/anima/*` | 仓库（Anima 快照） | 建议用同步脚本整份替换 |
| `presets/user_favs.json` | **本机生成**（收藏） | 随便改，不影响仓库 |
| `presets/user_random_pools.json` | **本机生成**（勾选场景池） | 同上 |
| `presets/user_char_outfit.json` | **本机生成**（角色服装锁定） | 同上 |
| `presets/user_motif_aspect.json` | **本机生成**（场景默认画幅覆盖） | 同上；删掉某条即退回推荐画幅 |

四个 `user_*.json` 不在仓库里（`.gitignore` 排除），首次运行时自动创建
（`user_motif_aspect.json` 在你第一次点卡片画幅徽标时才创建）。
仓库里放的是 `*.example.json` 空结构模板，想预置可直接复制改名。

### 升级与卸载

```bash
# 升级
cd <ComfyUI>/custom_nodes/Comfyui-K2-Editorial && git pull

# 卸载
# 直接删掉整个目录；用户态数据（收藏/勾选池）也随之消失，需要的话先备份 presets/user_*.json
```

升级后**必须重启** ComfyUI（Python 代码与 combo 列表都在进程内存里）。

| `服装` | 下拉 `自动（跟随母题）` / `保持母题原样` / 8 套版型 id | `"自动（跟随母题）"` |
| `单品` | STRING | `""` |
| `覆盖提示词` | STRING 多行 | `""` |
| `画面英文文字` | STRING | `""` |
| `画面不显示英文` | BOOLEAN | `false` |
| `画面文字模式` | 下拉 `全部替换` / `只留主标题` | `"全部替换"` |
| `角色随机池` | 下拉 `关闭` / `收藏角色` / `指定作品` | `"关闭"` |
| `角色随机作品` | STRING | `""` |
| `场景随机池` | 下拉 `关闭` / `收藏场景` / `勾选场景` | `"关闭"` |

8 套通用版型 id：`ceremonial_formal` / `technical_bodysuit` / `layered_drape` /
`panel_armor` / `court_formal` / `theatrical_cape` / `tailored_suit` / `fluid_drape`。

### 几个参数的实际含义

| 参数 | 怎么理解 |
| --- | --- |
| `角色` | 传的是 id。手写 key 只有 `miku` / `furina`；其他角色用 Anima 的完整 tag，例如 `raiden_shogun`、`hatsune_miku`、`furina_(genshin_impact)` |
| `母题` | 一条母题 = 一整篇长文。换母题等于整张画面重设计，不是换元素 |
| `单品` | 前缀区分来源：`char:xxx` 是角色官方服装预设，`lib:xxx` 是服装库单套。标签会叠在版型段之后 |
| `覆盖提示词` | 非空时**完全跳过**装配与随机，直接输出这段文本。用于手工微调后锁定 |
| `画面英文文字` | 替换母题原本印在画面上的文字。留空 = 用母题原文 |
| `画面不显示英文` | 优先级高于上一项，勾上就把所有画内文字（标题 / 编号 / 排印）清掉 |
| `角色随机池` | 开启后每轮从池里抽一个角色，**会覆盖** `角色` 的值；抽中结果写在 `元数据` 里 |
| `场景随机池` | 同上，覆盖 `母题`。空池会回退全库并在报告里标 `⚠` |

## 设置面板逐项

面板是唯一入口，节点上的五个核心控件被折叠隐藏（隐藏不影响序列化，工作流里仍保存值）。

### ① 角色页

| 区域 | 功能 |
| --- | --- |
| 左栏作品列表 | 287 个作品，按人数排序；`★ 收藏` 单独一档 |
| 搜索框 | 匹配中文名 / id / 英文作品名 / 中文作品名，260ms 防抖 |
| 网格 | 每页 72 位，带立绘、中文名、作品名；右上 ★ 收藏，右下 👗 表示已锁官方服装 |
| 随机抽取行 | 三档：关闭 / 收藏角色 / 指定作品；显示池大小，空池标 `⚠ 回退全库` |
| 右栏官方服装 | 该角色有预设时出现下拉，选定即写回 `单品` 并记住（下次自动带出） |

顶栏会显示当前角色库来源：`实时`（读 Anima）或 `内置 N 张图`（读快照）。

### ② 服装页

三组卡片：**自动 / 保持原样** → **8 套通用版型** → **角色官方预设** → **服装库（98 套 / 11 类）**。
服装库卡片按分类筛选，选中即写入 `单品`。

### ③ 场景页

| 行 | 内容 |
| --- | --- |
| 第 1 行 | `★ 只看收藏` / 分类（全部 · 3D 场景 · 平面海报 · 短提示词）/ 推荐画幅（全部 · 横 · 竖 · 通用 · 方） |
| 第 2 行 | 关键词搜索 + 场景标签（由母题正文自动生成，带条数） |
| 第 3 行 | 随机池三档 + `☑ 全选当前` / `⇄ 反选` / `✕ 清空勾选`，显示池大小 |
| 网格 | 553 条，卡片带缩略图、中文名、英文标题、词数、**画幅徽标（可点）**、勾选框、收藏星 |

点卡片 = 选中该母题并写回节点；按推荐画幅自动切 `画幅`；若母题登记了推荐角色，会同时切角色并把 `服装` 设为「保持母题原样」（保住原作服装）。重复点同一条不会覆盖你后来手选的设置。

**卡片上的画幅徽标可以点**（`竖屏 / 横屏 / 方屏 / 通用`）：点一下 `竖 → 横 → 方 → 竖` 循环，
点完会做两件事 ——

1. 把**这条母题的默认画幅**改掉，写进 `presets/user_motif_aspect.json`，下次再选它就是这个画幅；
2. 把**当前工作流的画幅**一起切过去（竖 `3:4` / 横 `16:9` / 方 `1:1`）；若面板上勾了「同步参数节点」，
   连 `XB_ImageParamsMaster` 也一并推过去。

`通用（both）` 不在三态循环里 —— 点它先落竖屏，之后照常走循环。想让某条退回母题自带的推荐值，
手工把 `user_motif_aspect.json` 里那一行删掉即可（也可以直接删整个文件，全部回到推荐值）。

### 右栏预览

常驻显示：角色立绘 + 名字 + 作品、服装、单品（含标签列表）、母题缩略图 + 词数 + 分类、
画内英文输入框 + 「不显示文字」勾选，底部是 `🎲 随机` / `生成预览` / `复制` 三个动作。

## 输出端口

| 端口 | 类型 | 内容 |
| --- | --- | --- |
| `提示词` | STRING | 成品长文（1500–2700 词），直接接 `CLIP Text Encode` 的 positive |
| `自检报告` | STRING | 篇幅 / 段数 / 色盘百分数 + 抽中信息 + 告警；装配失败时**首行**是原因 |
| `元数据` | STRING | JSON：角色 / 母题 / 画幅 / 服装 / 单品 / 词数 / 段数 / 种子 / 装配日志 / 抽中结果 |

成品长文同时会写进 PNG 元数据的 `k2ed_prompt` 字段（节点内部 + `extra_pnginfo`），
所以拖回一张图就能复原当时的提示词，不需要额外节点。

## 概念辨析

### 母题的 branch 为什么有两个来源

`seeds_*.json` 里的 `branch` 是**来源标记**，共 8 种（`scene` / `short` / `poster` /
`portrait-pose` / `night` / `material-narrative` / `baieguang-import` / 缺省）。
装配时凡不在 `(poster, short)` 的都走 scene 路径。

`manifest.json` 里的 `branch` 才是**分类契约**，构建脚本已把非标准值归一到三类
（`scene` 312 / `short` 226 / `poster` 15）。前端筛选读这份，所以两个来源不冲突。

### 服装优先级

```
角色官方预设（启用中）  >  服装库（启用中）  >  母题写死的服装  >  随机版型
```

- `服装 = 保持母题原样` 时完全不动母题里的服装描述（IP 名场面必须用这个）
- 选了 `单品` 但既不是 `char:` 也不是 `lib:` 前缀 → 忽略

### 随机池 vs 勾选池

| | 随机池 | 勾选池 |
| --- | --- | --- |
| 存哪 | 节点控件（`角色随机池` / `场景随机池`） | 服务端文件 `user_random_pools.json` |
| 为什么 | 模式要能进工作流、可复现 | 可能几百条 id，塞进节点会让工作流文件暴涨 |
| 抽取时机 | 每次执行、`random.seed` 之后 | 同左，按池内 id 抽 |

抽取结果会显示在节点摘要与自检报告里（`抽中：角色 xxx〔收藏角色（12 人）〕`）。

## 典型使用示例

### 1. 最小跑通（验证插件能用）

1. 新建节点 → 打开面板 → 场景页任选一条
2. 角色页任选一位
3. 节点 `提示词` 接 `CLIP Text Encode` positive，随便接个采样器
4. 排队，能出图即成功

### 2. 接进既有 Krea2 链路

把 `提示词` 接到你原有工作流的 positive 输入端，替换掉手写长文。
画幅建议用面板自动同步（面板底部勾「同步画幅到参数节点」），它会同时改
`XB_ImageParamsMaster` 的 `aspect_ratio` / `width` / `height`；非原生比例走 `Free` + 显式宽高。

### 3. 批量跑同一角色的多个母题

1. 场景页先把候选母题挨个点 `✓` 加入勾选池
2. 第 3 行选「勾选场景」
3. 拉高队列 batch（或重复执行），每轮自动换一条

要换角色同理：角色页开启「收藏角色」池，先把人收进收藏。

### 4. 复现某张图的提示词

两种路径：

- **从图里**：把出图拖回 ComfyUI，读 PNG 元数据的 `k2ed_prompt`
- **从节点**：关掉「每次重随机」，把 `随机种子` 固定成当时的值 —— 固定种子模式下，
  只要母题库 / 版型 / 收藏 / 勾选池没变，装配结果逐字节一致（这几份文件的指纹已进 `IS_CHANGED`）

### 5. 控制画内文字

| 想达到 | 操作 |
| --- | --- |
| 用母题原本的标题文字 | `画面英文文字` 留空 |
| 换成自己的词 | 填进 `画面英文文字`，位置 / 字体 / 材质描述保持不变 |
| 只要主标题，去掉编号 / 副标 | `画面文字模式 = 只留主标题` |
| 完全不要文字 | 勾 `画面不显示英文`（优先级最高） |

母题原本没有排印文字时，填了 `画面英文文字` 会新增一行排印描述。

## 常见问题 FAQ

### 安装

**1. 启动日志里没有 `[K2-Editorial]` 这行？**
目录名必须是 `Comfyui-K2-Editorial`，且 `__init__.py` 直接在目录下。被套成
`Comfyui-K2-Editorial/Comfyui-K2-Editorial/__init__.py` 是最常见的原因。

**2. 节点出现在列表里但点了没反应？**
`js/k2ed_panel.js` 没被加载。检查 `<ComfyUI>/extensions/Comfyui-K2-Editorial/k2ed_panel.js`
能否访问（浏览器直接打开这个 URL）；404 说明 `WEB_DIRECTORY` 没生效，重启一次。

**3. 面板打开是空白？**
前端请求 `/k2ed/manifest` 失败。按 F12 看网络面板，若 404 说明后端没注册路由（Python 报错被吞了，看启动日志）。

**4. `python tests/run_all.py` 报 `ModuleNotFoundError: folder_paths`？**
测试脚本会自动 stub 这个模块，正常不会报。如果报了，说明你改坏了 `tests/run_all.py` 顶部的加载段。

**5. 能不能不装 Anima-Wardrobe 单独用？**
能。内置副本已含 2432 角色 + 立绘 + 98 套服装，`K2ED_ANIMA_SOURCE=auto` 会自动回落。

### 结果与画面

**6. 生成的提示词只有 100 多词？**
大概率选中了 `short` 分支母题（226 条短提示词，本来就 4–8 段）。看自检报告的段数。

**7. 报告里 `⚠ 篇幅异常` 但图还能出？**
自检只是告警，不阻断。常见于 `k2p_*` / `k2s_cx_*` 这类既有设计档，它们不遵循长文体量。

**8. 换角色后脸部不像？**
母题里的身份锚点只保证「身份可读」，不保证像素级还原。冷门角色建议用 Anima 的完整 tag
（`角色` 填 `xxx_(作品)` 形式），并确认该 tag 在角色库里存在。

**9. 画面里出现两个人？**
母题正文结尾有 `no second figure` 之类负向段，但模型不一定听。优先换母题，或把 `画幅` 改宽/改窄改变构图。

**10. 画内文字乱码 / 拼错？**
提示词里的文字是给模型「画」的，不是渲染的。字数越多越容易错，建议 ≤ 3 个词，用 `画面文字模式 = 只留主标题`。

**11. 为什么服装没变？**
检查三件事：`服装` 是不是「保持母题原样」；该角色是不是启用了官方服装预设（预设优先级最高）；母题是不是写死了服装。

### 参数与行为

**12. `每次重随机` 关掉后结果还是变？**
同 seed 下只有「母题库 / 版型 / 收藏 / 勾选池 / 代码」都没变才逐字节一致。改过其中任一文件，`IS_CHANGED` 会让缓存失效并重跑（这是预期行为）。

**13. 三个随机池能不能放在控件中间？**
不能。`INPUT_TYPES["optional"]` 的顺序决定了 `widgets_values` 的下标，插到中间会让老工作流读错值。这是硬约束。

**14. `角色随机池` 抽中了我不想用的角色？**
池子来源三条：收藏角色 / 指定作品 / 全库回落。报告里会写 `⚠ 收藏角色为空，回退全库` —— 看到这个就说明池是空的。

**15. 勾选池里存了几百条，工作流文件会变大吗？**
不会。勾选池存服务端 `presets/user_random_pools.json`，节点里只有模式字符串。

**16. 能不能手动指定一条母题而不进面板？**
可以。API 工作流里直接给 `母题` 传 id；或用 `/k2ed/build?motif=<id>` 取预览。

**17. 覆盖提示词和面板的「生成预览」什么关系？**
`覆盖提示词` 非空时不走装配。面板预览走 `/k2ed/build`，不读 `覆盖提示词`，所以两者可能不一致 —— 这是设计（预览永远显示装配结果）。

### 性能

**18. 装配一次要多久？**
约 1.7 ms（含 553 条母题的字典查找与文本拼接）。`load()` 有指纹缓存，命中时 0.2 ms。

**19. 面板第一次打开慢？**
要拉 `/k2ed/manifest`（约 340 KB）与 72 张立绘。之后走浏览器缓存（带 `?v=mtime` 版本号）。

**20. 36 MB 的立绘能不能删？**
能删 `thumbs/anima/`（角色立绘 22 MB）与 `thumbs/motifs/`（母题预览 14 MB），插件功能不受影响，只是面板无图。删完跑一次 `tests/run_all.py` 会红（manifest 校验要求缩略图存在），属预期。

### 合规

**21. 生成的图能商用吗？**
本插件只生成提示词，图片版权取决于你用的模型许可与所在地区的 AI 内容规定。角色 IP 归权利人，商用需自行取得授权。

**22. 为什么仓库里的服装库只有 98 套？**
公开版用 `tools/make_sfw_bundle.py` 精简过：只留 L0–L1、剔除 `nsfw_outfit` 分类，共剔除 37 套。装 Anima-Wardrobe 后会自动用它的完整库（167 套），不受影响。

**23. AGPL 对我意味着什么？**
如果你修改本插件并通过网络提供服务，需要公开修改后的源码。个人本地使用没有额外义务。

## 注意事项与限制

- **改母题 / 版型 / 代码 → 必须重启 ComfyUI**。Python 模块与 combo 列表都在进程内存里；只有 `manifest.json` 与用户态文件是热读的。
- **固定种子模式的缓存失效**依赖 `IS_CHANGED` 里的文件指纹（母题库 / 版型 / 收藏 / 勾选池 + 3 个 py 的 mtime）。改了这些文件，同种子也会重跑。
- **新增控件只能加在末尾**，且新增后要同步 `IS_CHANGED` 的返回元组，否则固定种子下换控件值不会重跑。
- **`validate()` 的角色残留检查**只对母题登记过 `character` 的 30 条生效；其余母题不写死角色。
- **`random` 状态已隔离**：`generate()` 用完即复原全局状态，同工作流下游的随机节点不会被钉住。
- **缩略图路由**是 `/k2ed/thumb/` + manifest 里的 `thumb` 字段原值（字段自带 `thumbs/` 前缀）。
- **不支持**：多角色同框（母题是单人设计）、视频、批量导出提示词文件（用 CLI 或 API 自己循环）。
